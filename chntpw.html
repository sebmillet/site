chntpw

dim. 15 décembre 2024
D'après
https://whatisgon.wordpress.com/2010/01/28/chntpw-tutorial-resetting-windows-passwords-editing-registry-linux

Pour déverrouiller un compte sous Windows avec chntpw (disponible par défaut dans SystemRescueCD, peut être installé facilement sur AntiX).

  • Aller dans le répertoire :

    .../Windows/System32/config

Le répertoire complet dépend évidemment du point de montage de la partition Windows + selon la version de Windows, la casse peut changer. Ci-dessus, la casse correspond à Windows 10 en décembre 2024.

  • Exécuter :
chntpw -i SAM
  • Ensuite, naviguer dans l'interface de chntpw.
