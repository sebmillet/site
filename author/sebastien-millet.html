Enlever les DRM
lun. 30 décembre 2024

  • Le but est double :

    1. Récupérer un epub disponible sur la kobo - un epub acheté.
    2. Ôter les DRM du fichier.

1) Préparation

1.1 Installation de gourou

Installer gourou. Sur Arch par exemple, gourou est disponible sur AUR. Dans l'hypothèse où c'est l'outil yay qui est utilisé pour installer des paquets d'AUR, exécuter :

yay gourou

1.2 Activer adept (session utilisateur)

Il faut avoir un compte Adobe Digital Editions.

Se connecter à :

https://account.adobe.com/

et suivre les instructions pour se créer un compte.

Ensuite exécuter :

adept_activate -u sebastien.millet@gmail.com

Si l'activation réussit, cela génère le fichier : ~/.config/adept/activation.xml.

2) Récupération du fichier epub sur le PC

2.1) Téléchargement du fichier ACSM

Il faut d'abord obtenir le fichier ACSM du livre. Avec kobo, je me connecte à

https://authorize.kobo.com/fr/fr/Signin?returnUrl=https://www.kobo.com/fr/fr?changeLanguage=True

puis je clique en haut à droite sur Mon compte et enfin sur le menu Livres.

Ensuite sur la carte du livre que je souhaite télécharger, je clique sur le menu 'trois petits points' et sur Télécharger.

Le navigateur récupère un fichier URLLink.acsm dans le dossier des téléchargements.

2.2) Téléchargement du fichier epub avec le fichier ACSM

Exécuter (exemple avec Bifrost n° 116) :

$ acsmdownloader URLLink.acsm
Created Bifrost n° 116 - dossier Catherine Dufour.epub

Si tout se passe bien, acsmdownloader indique le nom du fichier .epub créé.

À ce stade le fichier est protégé, on peut le voir avec par exemple calibre qui affiche un message d'erreur

Ce livre est verrouillé par des DRMs [...]

3) Suppression des DRMs

Exécuter (même exemple) :

$ adept_remove Bifrost\ n°\ 116\ -\ dossier\ Catherine\ Dufour.epub
DRM removed from Bifrost n° 116 - dossier Catherine Dufour.epub

Si tout se passe bien, adept_remove confirme l'opération. On peut le vérifier facilement en l'ajoutant à calibre par exemple, qui affiche le contenu du livre sans erreur.
