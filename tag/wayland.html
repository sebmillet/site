Installer et configurer wayvnc

wayvnc côté serveur sera utilisé à travers un tunnel SSH.

L'objectif ici est de démarrer wayvnc :

  • Sur la session graphique utilisateur (surtout pas système)
  • À l'écoute uniquement en local (127.0.0.1), du fait du tunnel SSH.
  1. Installer le paquet wayvnc.
  2. Créer le dossier ~/.config/systemd/user.
  3. Dans ce dossier, créer le fichier wayvnc.service.

Le nom complet du fichier est donc

~/.config/systemd/user/wayvnc.service

  1. Contenu du fichier :
[Unit]
Description=WayVNC (user session)
After=graphical-session.target
Wants=graphical-session.target

[Service]
ExecStart=/usr/bin/wayvnc 127.0.0.1
Restart=on-failure
RestartSec=2

[Install]
WantedBy=default.target
  1. Lancer le service et le configurer pour démarrer automatiquement :
systemctl --user daemon-reload
systemctl --user enable wayvnc.service
systemctl --user start wayvnc.service

# Vérifier le status
systemctl --user status wayvnc.service

Installer et configurer remmina

Sous Arch, installer le paquet remmina.

  1. Créer une entrée
  2. Protocole : choisir Greffon VNC pour Remmina
  3. Onglet Basique, champ Serveur, écrire :

localhost:5900

  1. Onglet Tunnel SSH, sélectionner Personnalisée et écrire :

192.168.0.33:38000

  1. Dans Authentification SSH, champ Type d'authentification, choisir

Fichier d'identité SSH

  1. Nom d'utilisateur, écrire :

maisonadm

  1. Champ Fichier contenant la clef SSH privée, sélectionner :

~/.ssh/maisonadm@maison-rp_id_rsa

Résolution du client par rapport au serveur

Dans la fenêtre de session distante remmina, barre de gauche, cliquer sur

Commuter la mise à jour dynamique de la définition.

pour adapter l'affichage local au distant, c'est-à-dire, éviter l'affichage d'ascenseurs si la résolution du serveur est supérieure.
