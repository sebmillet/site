Installation de kodi sur raspbian

Installer le paquet kodi.

Démarrage de kodi automatiquement sur raspbian

Créer le dossier ~/.config/autostart.

Y créer le fichier kodi.desktop

Contenu :

[Desktop Entry]
Type=Application
Name=Kodi
Exec=kodi
X-GNOME-Autostart-enabled=true

Configuration de KODI

1 Premier démarrage

Activer Inputstream FFmpeg Direct Activer IPTV Simple Client Activer Version Check

2 Langue

  • Dans KODI, aller dans Settings -> Interface -> Regional, champ Language, choisir French
  • Au même endroit, champ Dispositions du clavier virtuel, choisir French AZERTY
  • Toujours au même endroit, champ Format régional prédéfini, choisir France

4 Lancer un flux avec streamlink

Installer le paquet streamlink.

streamlink fonctionne en ligne de commande, ce qui est pratique pour le tester.

Exemple qui doit fonctionner sans modifier streamlink :

streamlink https://www.france.tv/france-5/direct.html best

L'exemple ci-dessous ne fonctionne pas :

streamlink https://www.arte.tv/fr/live/arte-tv/ best

Pour utiliser streamlink avec Arte, il faut modifier le plugin ArteTV. Constaté le 2026-07-05.

Créer le fichier ~/artetv.py.patch

Contenu du fichier :

+++ artetv.py       2026-07-05 09:25:53.788643825 +0200
@@ -34,7 +34,13 @@

     def _get_streams(self):
-        self.id = self.match["video_id"] if self.matches["vod"] else "LIVE"
+        video_id = None
+
+        if hasattr(self.match, "groupdict"):
+            video_id = self.match.groupdict().get("video_id")
+
+        self.id = video_id if video_id else "LIVE"
+

         json_url = self.API_URL.format(
             language=self.match["language"],

Ensuite exécuter les commandes suivantes :

cd /usr/lib/python3.14/site-packages/streamlink/plugins
patch artetv.py < ~/artetv.py.patch

Attention si streamlink a été installé avec pipx (donc dans l'environnement utilisateur, dans ~/.local/bin), dans ce cas le répertoire du plugin est différent :

cd ~/.local/pipx/venvs/streamlink/lib/python3.11/site-packages/streamlink/plugins
patch artetv.py < ~/artetv.py.patch

La commande streamlink doit désormais fonctionner pour Arte :

streamlink https://www.arte.tv/fr/live/arte-tv/ best

4.1 streamlink sur raspberry

La version streamlink sur mon raspberry (bookworm = V12) est 5.2.1, trop ancienne en 2026.

Exécuter :

apt-get install pipx
pipx install streamlink

Ensuite il faut s'assurer que le streamlink lancé par défaut est bien celui qui se trouve dans le répertoire ~/.local/bin. Cela nécessite de modifier la variable PATH, dans ~/.bashrc typiquement (si le shell est bash évidemment).

Au besoin, exécuter

pipx ensurepath

Et dans tous les cas, vérifier le résultat :

maisonadm@maison-rp:~ $ streamlink --version
streamlink 8.4.0

5 Créer un addon kodi avec streamlink

C'est assez complexe et il vaut mieux utiliser des alternatives plus robustes, mais s'il n'y a pas le choix...

Exemple de plugin pour MyArteTV, qui fait appel à streamlink pour l'URL https://www.arte.tv/fr/live/arte-tv/

5.1 Créer le répertoire de l'addon

Créer le répertoire plugin.video.myartetv dans ~/.kodi/addons.

5.2 Créer le fichier addon.xml

Le fichier est situé dans le répertoire qui vient d'être créé, nom complet : ~/.kodi/addons/plugin.video.myartetv/addon.xml

Contenu du fichier :

<addon id="plugin.video.myartetv" name="My Arte avec streamlink" version="1.0.0" provider-name="local">
  <extension point="xbmc.python.pluginsource" library="default.py">
    <provides>video</provides>
  </extension>
  <requires>
    <import addon="xbmc.python" version="3.0.0"/>
  </requires>
</addon>

5.3 Créer le fichier default.py

Au même endroit que addon.xml, donc le nom complet est : ~/.kodi/addons/plugin.video.myartetv/default.py

Contenu du fichier :

import xbmc
import subprocess
import socket
import time

url = "https://www.arte.tv/fr/live/arte-tv"
port = 8765

cmd = [
    "streamlink",
    url,
    "best",
    "--player-external-http",
    "--player-external-http-port",
    str(port)
]

subprocess.Popen(
    cmd,
    start_new_session=True,
    stdout=subprocess.DEVNULL,
    stderr=subprocess.DEVNULL
)

def wait_port(host, port, timeout=10.0):
    start = time.time()
    while time.time() - start < timeout:
        try:
            with socket.create_connection((host, port), timeout=0.2):
                return True
        except OSError:
            time.sleep(0.05)
    return False

if wait_port("127.0.0.1", port):
    xbmc.Player().play(f"http://127.0.0.1:{port}/")
else:
    xbmc.log("MYARTETV ERROR: streamlink not ready", xbmc.LOGERROR)

On a donc comme structure :

~/.kodi/addons/plugin.video.myartetv
├── addon.xml
└── default.py

Note

Cette version de default.py risque de produire des zombies, chaque fois que streamlink s'arrête. J'ai fait quelques essais avec chatgpt pour améliorer le code, les résultats ne sont pas probants. De toute façon un tel addon est un plan B.

6 Catch-up TV and More

Cet addon kodi permet de regarder la plupart des chaînes, avec le replay.

La qualité est bonne,

Sur raspberry, la version disponible par défaut est trop ancienne, il faut ajouter la source de l'addon à la main et l'installer depuis cette source.

Dans Paramètres -> Système -> Extensions, cocher Sources inconnues

Dans Paramètres -> Gestionnaire de fichiers, double-cliquer sur Ajouter une source

Double-cliquer sur <Aucun(e)>

Saisir l'URL : https://catch-up-tv-and-more.github.io/repo/

Double-cliquer sur repo (nom de la source) et choisir par exemple :

Catch-up TV & More source

Dans Paramètres -> Extensions, cliquer sur Installer d'un fichier Zip

Cliquer sur le nom choisis, ici Catch-up TV & More source

Cliquer sur Stable_channel

Cliquer sur repository.catchuptvandmore.stable-0.0.6.zip

Après un court délai, en haut à gauche s'affiche Extension installée

Dans Paramètres -> Extensions, cliquer sur Installer d'un dépôt

Cliquer sur Catch-up TV & More Release repository

Cliquer sur Extensions Vidéos

Cliquer sur Catch-up TV & More

Cliquer (en bas à droite) sur Installer

Une fenêtre s'affiche indiquant Les extensions supplémentaires suivantes seront installées

3 extensions sont listées dans cette fenêtre :

  • InputStream Helper, min 0.3.3 => À installer 0.8.5
  • youtube-dl Control, min 19.912.1 => À installer 25.11.30+matrix.1
  • Catch-up TV & More channel logos and artwork, min 1.0.0 => À installer 1.0.31

Cliquer sur chacune des 3 extensions et dans la fenêtre qui s'affiche (page de l'extension), cliquer en bas à droite sur Installer.

Ensuite cliquer sur "OK".

Depuis la fenêtre d'accueil, lancer l'extension Catch-up TV & More

Cliquer TV en direct -> France -> France 2 (par exemple)

Une fenêtre s'affiche indiquant Widevine CDM est nécessaire

Cliquer sur Installer Widevine

Cliquer J'accepte (licence EULA Widevine CDM)

Une fenêtre d'information s'affiche, indiquant

En raison des droits de distribution, Widevine CDM doit être extrait d'une image de récupération de Chrome OS. Ce processus nécessite au moins 1.5GiB d'espace disque disponible. Souhaitez-vous continuer ?

Cliquer Oui.

Le téléchargement prend beaucoup de temps et une fois terminé, la chaîne démarre.

9.2 Configuration de windscribe

  • Dans l'écran principal, quand le VPN est actif, vérifier que FIREWALL est coché.
  • Dans les options General, vérifier que Launch on Startup est coché. Normalement c'est déjà le cas.
  • Dans les options Connection, cocher Allow LAN Traffic.

ATTENTION À NE FAIRE QUE LORSQU'ON EST CERTAIN QUE C'EST OK

Le souci est que si le rpi n'est pas joignable au démarrage, ça se complique vite.

  • Dans les options Connection, cocher Auto-Connect.
