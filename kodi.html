Installation de kodi sur raspbian

apt-get install kodi

Démarrage de kodi automatiquement sur raspbian

Exécuter

mkdir -p ~/.config/autostart

Créer le fichier ~/.config/autostart/kodi.desktop

Contenu :

[Desktop Entry]
Type=Application
Name=Kodi
Exec=kodi
X-GNOME-Autostart-enabled=true

Configuration de KODI

1) Langue

  • Dans KODI, aller dans Options -> Interface -> Regional, champ Language, choisir French
  • Au même endroit, champ Disposition du clavier virtuel, choisir French AZERTY

3) Lancer un flux avec streamlink

Installer le paquet

streamlink

Ensuite, exemple qui doit fonctionner sans modifier streamlink.

streamlink https://www.france.tv/france-5/direct.html best

Cet exemple ci-dessous ne fonctionne pas :

streamlink https://www.arte.tv/fr/live/arte-tv/ best

Pour utiliser streamlink avec Arte, il faut modifier le plugin ArteTV. Constaté le 2026-07-05.

Créer le fichier ~/artetv.py.patch

4) Créer un addon kodi avec streamlink

C'est assez complexe et il vaut mieux utiliser des alternatives plus robustes, mais s'il n'y a pas le choix...

Exemple de plugin pour MyArteTV, qui fait appel à streamlink pour l'URL https://www.arte.tv/fr/live/arte-tv/

4.1) Créer le répertoire de l'addon

~/.kodi/addons/plugin.video.myartetv
cd ~/.kodi/addons/plugin.video.myartetv

4.2) Créer le fichier addon.xml

Contenu du fichier :

<addon id="plugin.video.myartetv" name="My Arte avec streamlink" version="1.0.0" provider-name="local">
  <extension point="xbmc.python.pluginsource" library="default.py">
    <provides>video</provides>
  </extension>
  <requires>
    <import addon="xbmc.python" version="3.0.0"/>
  </requires>
</addon>

4.2) Créer le fichier default.py

Contenu du fichier :

import xbmc
import subprocess
import socket
import time

url = "https://www.arte.tv/fr/live/arte-tv"
port = 8765

cmd = [
    "streamlink",
    url,
    "best",
    "--player-external-http",
    "--player-external-http-port",
    str(port)
]

subprocess.Popen(cmd)

def wait_port(host, port, timeout=5.0):
    start = time.time()
    while time.time() - start < timeout:
        try:
            with socket.create_connection((host, port), timeout=0.2):
                return True
        except OSError:
            time.sleep(0.05)
    return False

if wait_port("127.0.0.1", port):
    xbmc.Player().play(f"http://127.0.0.1:{port}/")
else:
    xbmc.log("MYARTETV ERROR: streamlink not ready", xbmc.LOGERROR)

4.3 Activation

Au démarrage de kodi, kodi détecte ce nouvel addon et demande s'il faut l'activer. Répondre Oui.
